# PraySkyine Project Proposal

## Project Description
praySkyline is a website designed to support the Pray Skyline ministry by providing users prayer prompts for the people in surrounding areas of each stop along the Honolulu Skyline light metro route.

## Project Inspiration
"First of all, then, I urge that supplications, prayers, intercessions, and thanksgivings be made for all people," (1 Timothy 2:1)  

praySkyline is developed in response to the start of Pray Skyline. The idea of a website is inspired by websites of other transit prayer ministries such as prayYamanote and Pray Osaka Loop. We plan to use these and other Christian prayer web apps as inspiration during the design process of praySkyline.

## Goals
- Enable new Pray Skyline participants to easily jump into prayer on the rail.
- Grow intercession to Jesus Christ on behalf of Oahu.
- Increase awareness of Oahu's needs among the local and global church.

## Objectives
Create a website that will provide Christians guidance on how to pray along the Honolulu Skyline.

## Roles and Responsibilities

## Literature Review
### [prayYamanote](https://prayyamanote.com/en/)
The website consists of 1 webpage (and [a mirror one in Japanese](https://prayyamanote.com/ja/)) containing data about the ministry and the stops on the line. The first section on the webpage introduces prayYamanote and provides information on how to participate in ministry events. There is a dropdown menu titled "CHOOSE YOUR STATION" that's always accessible no matter how far the user has scrolled down, from which users can click an anchor link that scrolls to the section for the selected station. The station descriptions and prayer points often name nearby churches and ministries if available.  
Like the prayYamanote website accomplishes, we want users to be able to quickly and easily navigate to any station's information section at any time. We also want to highlight nearby ministries but may need to discern which ones to list.

### [Osaka Loop Prayer](https://loop.adamgaskins.dev)
This website works ok on desktop but looks like it was made for mobile. 

## Proposed Work

### Users
#### End Users
We expect end users to primarily be participants of Pray Skyline events. However, we also expect end users to include Christian residents and visitors outside of Pray Skyline events.
#### Content Administrators
Content Administrators will be responsible for editing or updating content for the end users.
#### System Administrators
System Administrators will be responsible for securing, deploying, and maintaining the website.

### Scope
#### In-scope Items

- Collect data on the locations, people groups, and ministry needs around the stops along Skyline.
- Write content such as area descriptions and prayer prompts.
- Create user stories and user flows.
- Create a user guide on how to use the website.
- Create an About page informing people about the Pray Skyline ministry.
- Conduct usability, accessability, and security testing.
- Host the website.

#### Out-of-scope Items
- Support for other languages.

### Features
- Webpage with introduction and list of prayer requests for each stop.
- About PraySkyline page with links to social media page(s).
- Contact form for reporting website issues.
- Prayer guide PDF for offline use.
