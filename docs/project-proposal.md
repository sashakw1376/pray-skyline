# Project Proposal

## Project Description
praySkyline is a web application designed to support the Pray Skyline ministry. praySkyline provides users prayer prompts for the people in surrounding areas of each stop along the Honolulu Skyline light metro route.

## Project Inspiration
praySkyline is developed in response to the start of Pray Skyline. The idea of a web app is inspired by web applications of other transit prayer ministries such as prayYamanote and Pray Osaka Loop. We plan to use these other web apps as inspiration during the design process of praySkyline.

## Target Users
We expect the primary users to be participants in the weekly Pray Skyline ministry. However, we want to increase access so more Christians have access to prayer resources for the island of Oahu.

## Project Impact Goals
Saturate Oahu with prayer.
Increase awareness of Oahu's needs among the global church.

## Project Components
Collect data on the areas around the stops along Skyline.
Design web application.
Create prayer prompt content.
Implement web application.
