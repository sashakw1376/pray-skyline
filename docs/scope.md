# Scope of Work

## Project Description
praySkyline is a web application designed to support the Pray Skyline ministry by providing users prayer prompts for the people in surrounding areas of each stop along the Honolulu Skyline light metro route.

## Project Inspiration
"First of all, then, I urge that supplications, prayers, intercessions, and thanksgivings be made for all people," (1 Timothy 2:1)  

praySkyline is developed in response to the start of Pray Skyline. The idea of a web app is inspired by web applications of other transit prayer ministries such as prayYamanote and Pray Osaka Loop. We plan to use these and other Christian prayer web apps as inspiration during the design process of praySkyline.

## Goals
- Enable new Pray Skyline participants to easily jump into prayer on the rail.
- Grow intercession to Jesus Christ on behalf of Oahu.
- Increase awareness of Oahu's needs among the local and global church.

## Objectives
Create a web application that will provide Christians guidance on how to pray along the Honolulu Skyline.

## Users
### End Users
We expect end users to primarily be participants of Pray Skyline events. However, we also expect end users to include Christian residents and visitors outside of Pray Skyline events.
### Content Administrators
Content Administrators will be responsible for editing or updating content for the end users.
### System Administrators
System Administrators will be responsible for securing, deploying, and maintaining the application, as well as implementing new features. System Administrators will also push content changes to the application.

## Deliverables
Web application that's publicly accessible via the Internet.


## In-scope Items

- Collect data on the areas around the stops along Skyline.
- Write content such as area descriptions and prayer prompts.
- Create user stories and user flows.
- Create a user guide on how to use the web application.
- Create an About page informing people about the Pray Skyline ministry.
- Conduct user and security testing.
- Host the web application.

## Out-of-scope Items
- Support for other languages
- Contact form
- CMS integration
